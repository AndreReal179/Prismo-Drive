# Prismo Admin

Programa de administração do Prismo Drive para Windows.

- O GitHub gera o instalador sozinho sempre que esta pasta muda (workflow "Gerar Prismo Admin (Windows)").
- O instalador fica em **Releases**, como `admin-v1.0.N` (pré-lançamento, separado das versões do app).
- Entre com a conta de administrador do Prismo Drive (e-mail e senha).
- Antes do primeiro uso, rode no Supabase o SQL `PrismoDrive/supabase/migrations/20261121_painel_admin.sql`.
